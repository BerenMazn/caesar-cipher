# Caesar Cipher (Sezar Sifrelemesi) Araci

Bu proje, tarihin en bilinen ve en eski sifreleme tekniklerinden biri olan Sezar Sifrelemesi (Caesar Cipher) algoritmasini Python 3 kullanarak terminal üzerinde calistiran basit bir komut satiri aracidir.

## Özellikler
- Girilen metinleri belirlenen kaydirma sayisina (shift) göre sifreler.
- Sifrelenmis metinleri ayni anahtar ile orijinal haline getirir.
- Bosluk, sayi ve noktalama isaretlerini koruyarak sadece alfabetik karakterleri isler.

## Kurulum ve Calistirma
1. Python 3 sürümünün yüklü oldugundan emin olun: python3 --version
2. Betigi calistirin: python3 caesar_cipher.py
